# Air Flamme Énergie — Site vitrine professionnel

Site vitrine responsive réalisé pour une entreprise de ramonage et d'entretien de poêles à bois et granulés dans le Var.

## Objectif du projet

Créer un site professionnel permettant de :
- présenter les prestations de l'entreprise ;
- améliorer la visibilité locale sur Google ;
- faciliter la prise de contact ;
- rassurer les clients avec des informations claires ;
- centraliser les services, tarifs, zones d'intervention et conseils.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript vanilla
- Responsive design
- SEO local
- Git / GitHub
- Déploiement GitHub Pages

## Fonctionnalités

- Page d'accueil optimisée
- Page services
- Page informations et conseils
- Page contact avec formulaire
- Mentions légales
- CGV
- Sitemap XML
- Robots.txt
- Bannière cookies
- Protection email
- Menu burger responsive

## Ce que j'ai appris

- Structurer un site multi-pages
- Organiser les fichiers CSS et JS
- Améliorer le référencement local
- Créer une interface claire pour un artisan
- Déployer un site statique en ligne
